## The whole setup

<Steps>
  <Step title="Download the Mac beta">
    [Download Vibeconferencing](https://github.com/wanderingstan/vibeconf-app/releases/latest),
    drag it to Applications, and open it.
  </Step>
  <Step title="Restart Claude Code once">
    The app adds the `vibeconferencing` MCP and `/join-call` when Claude Code is
    available.
  </Step>
  <Step title="Open a Meet and run">
    ```text
    /join-call
    ```
    Click **Admit** when the agent appears in Google Meet.
  </Step>
</Steps>

<Note>
  Requires an Apple Silicon Mac and Claude Code. The current release is an
  open-source beta.
</Note>
