---
title: "Quickstart"
description: "Download -> restart Claude Code -> /join-call -> Admit."
---

<Note>
  **You need:** an Apple Silicon Mac and
  [Claude Code](https://claude.com/claude-code) installed.
</Note>

<Steps>
  <Step title="No Claude Code yet? Install it first">
    In Terminal:
    ```bash
    curl -fsSL https://claude.ai/install.sh | bash
    ```
    Then run `claude` in any project directory and follow the sign-in prompt.
    (Prefer a package manager? `npm install -g @anthropic-ai/claude-code` or
    `brew install claude-code` work too.) Already have it — skip ahead.
  </Step>
  <Step title="Install Vibeconferencing">
    [Download the latest Mac beta](https://github.com/wanderingstan/vibeconf-app/releases/latest),
    open the DMG, and drag Vibeconferencing to Applications.
  </Step>
  <Step title="Open it and allow access">
    Allow **Microphone**, **Camera**, and browser **Automation**. Screen Recording
    is optional and is used when the agent shares its whiteboard.
  </Step>
  <Step title="Restart Claude Code once">
    The app connects its bundled `vibeconferencing` MCP when Claude Code is
    available. Quit and reopen Claude Code after installing the app.
  </Step>
  <Step title="Open Google Meet and run">
    In the Claude Code session for your project:
    ```text
    /join-call
    ```
    The app finds the Meet open in your browser. Click **Admit** when the agent
    knocks, then talk to it.
  </Step>
</Steps>

That's the shipped path. There is no first-run setup wizard in the current beta.

<Tip>
  Codex can connect with a
  [manual MCP setup](https://github.com/wanderingstan/vibeconf-app/blob/main/docs/codex.md).
  Claude Code is the primary released path.
</Tip>
