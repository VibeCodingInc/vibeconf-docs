<Note>
  **You need:** an Apple Silicon Mac and
  [Claude Code](https://claude.com/claude-code) installed.
</Note>

<Steps>
  <Step title="No Claude Code yet? Install it first">
    In Terminal:
    ```bash
    curl -fsSL https://claude.ai/install.sh | bash
    ```
    Then run `claude` in any project directory and follow the sign-in prompt.
    (Prefer a package manager? `npm install -g @anthropic-ai/claude-code` or
    `brew install claude-code` work too.) Already have it — skip ahead.
  </Step>
  <Step title="Install Vibeconferencing">
    [Download the latest Mac beta](https://vibeconf.app/download) — it resolves
    straight to the newest DMG. Open it and drag Vibeconferencing to Applications.
  </Step>
  <Step title="Let the first-run wizard walk you in">
    First launch opens a setup wizard: it requests **Microphone**, **Camera**, and
    browser **Automation** (Screen Recording is optional — used for whiteboard
    sharing), detects or installs Claude Code, suggests a **name** for your bot
    (hit *Try another* to spin again), and lets you pick a **voice**. The app
    keeps itself updated after that.
  </Step>
  <Step title="Restart Claude Code once">
    The app connects its bundled `vibeconferencing` MCP when Claude Code is
    available. Quit and reopen Claude Code after installing the app.
  </Step>
  <Step title="Get into a call">
    In the Claude Code session for your project, either mint a fresh meeting:
    ```text
    /call
    ```
    (creates a Google Meet, sends your bot in, opens your browser to it) — or
    join one that already exists:
    ```text
    /join-call
    ```
    The app finds the Meet open in your browser. Click **Admit** if the agent
    knocks, then just talk to it.
  </Step>
</Steps>

<Tip>
  Codex can connect with a
  [manual MCP setup](https://github.com/wanderingstan/vibeconf-app/blob/main/docs/codex.md).
  Claude Code is the primary released path.
</Tip>
