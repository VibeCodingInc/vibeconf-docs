**Rung 5 of [the first hour](/first-hour).** Someone describes something visual; you make it
and put it on screen while they're still describing it.

Your human needs one key. You do everything else.

## 1 · The key (their two minutes, once)

Say this, at a lull — never mid-thought:

> *"I could actually make that — about a minute. It needs one key from fal.ai, which is a
> single account that reaches most of the image and video models. Want to grab it now or
> should I skip it?"*

If yes: they sign up at **fal.ai**, copy an API key, and put it somewhere your session can
read — an env var (`FAL_KEY`) or a keys file you already source. **Never ask them to paste a
key into the chat or say it out loud on a recorded call.** If they offer to, stop them.

## 2 · Make the image

```bash
curl -s https://fal.run/fal-ai/bytedance/seedream/v4/text-to-image \
  -H "Authorization: Key $FAL_KEY" -H "Content-Type: application/json" \
  -d '{"prompt":"<prompt>","image_size":"landscape_16_9"}'
```

Returns a URL; download it locally. **Use `seedream/v4` when the image contains any text** —
it is the only model in this family that reliably spells. Other models produce beautiful
images with typos in the headline, which is worse than no image.

## 3 · Show it

Use `update_whiteboard`'s **`image_path`** parameter with an absolute local path. That is the
only correct way:

- ❌ a `file://` link in markdown — the board renders in a sandbox that can't load it
- ❌ a hand-built base64 data URI — enormous and pointless
- ✅ `image_path: "/abs/path/to/image.jpg"` — registered and embedded for you

If nothing is currently being presented, `start_share` too. If another bot is already
presenting, **update only** — never grab the board.

## 4 · Doing it well

- **Proofread before you show it.** Open the image and read any text in it. Models typo. A
  typo'd headline on a shared screen is a worse outcome than "I couldn't make that."
- **One image, not four.** A grid of options is a design review; the room wanted a picture.
- **Say what you're doing before the pause.** "Making that now, about a minute" — otherwise
  sixty seconds of silence reads as a dead bot.
- **Landscape by default** (`landscape_16_9`); the board is wide and the tiles crop the right.
- **Their words, not yours.** Build the prompt from what they actually said. If they said
  "grumpy and industrial," don't quietly upgrade it to "moody, cinematic."
- **Don't generate people who exist.** A recognisable real person's face needs that person's
  yes, and a call is not the place to get it.

## When it fails

Say so in one sentence and move on — "that came back wrong, want me to try once more or drop
it?" A cheerful retry loop while the room waits is worse than the missing image.
