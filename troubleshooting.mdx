---
title: "Troubleshooting"
description: "Four common problems and the shortest fix."
---

<AccordionGroup>
  <Accordion title="/join-call is missing" icon="plug">
    Make sure Vibeconferencing is open. Restart Claude Code once after installing
    the app. If the command is still missing, run `/mcp` and reconnect
    `vibeconferencing`.
  </Accordion>
  <Accordion title="The app cannot find the Meet" icon="video">
    Open the Meet in your browser and run `/join-call` again. You can also pass
    the full Meet URL to `join_call`.
  </Accordion>
  <Accordion title="The agent is waiting" icon="hourglass">
    Click **Admit** in Google Meet. If the request expired, leave and run
    `/join-call` again.
  </Accordion>
  <Accordion title="The agent cannot hear or speak" icon="microphone">
    Reopen App Settings and confirm Microphone and Camera permission. Leave the
    call, then run `/join-call` again.
  </Accordion>
</AccordionGroup>

<Note>
  App open + Meet open -> `/join-call` -> **Admit**.
</Note>
